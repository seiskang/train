CHAPTER 01

AI에게 내 질환과 일과 말하기 (기획)

생성형 AI를 다룰 때 가장 중요한 것은 "내 일상 생활 패턴을 시간 순서대로 명확히 설명하는 것"입니다. 막연하게 "건강 앱 만들어줘"라고 하면 나에게 필요 없는 기능만 가득 생깁니다.

⏰

💊
약/측정 항목
혈압, 체중, 고혈압·뇌경색약 O/X

💡 이윤재 원장의 실제 프롬프트 모범 예시

"앱의 핵심 기능들을 정리해 볼게.
1. 혈압 측정: 오전 7시, 저녁 10시 하루 두 번 정해진 시간 알람
2. 체중 측정: 오전 7시 30분 아침 공복 상태 측정
3. 아침 약 복용: 오전 8시 (고혈압, 고지혈증, 협심증, 뇌경색 약 안내)
4. 저녁 약 복용: 오후 7시 30분 저녁 약 안내
5. 복약 유무는 O, X로 체크하고 혈압과 체중은 숫자를 직접 입력하게 해줘.
6. 나는 시각장애인이라 조금밖에 안 보여. 니가 알아서 맞춤형으로 만들어줘."

시니어 대상 디지털 도구는 화려함보다 '직관성과 시인성'이 생명입니다.

🔊 "혈압 120에 80이 저장되었습니다" 음성 확인
  • 1. 고대비(High Contrast) 배색: 칠흑 같은 검정 배경에 형광 노랑, 시안 블루 글씨를 사용하여 눈부심 없이 선명하게 보입니다.
  • 2. 특대형 터치 영역: 손끝 감각이 무디거나 수전증이 있어도 빗나가지 않도록 버튼 높이를 최소 75px 이상 크게 설계합니다.
  • 3. 한국어 음성 안내(TTS): 화면을 보지 않아도 알람과 저장 결과를 말로 똑똑히 들려줍니다.
CHAPTER 03

컴퓨터에서 길 찾기 (탐색기 주소창 마법)

시니어분들이 가장 무서워하는 것이 바로 파워쉘(PowerShell)의 까만 화면입니다. 하지만 마우스 클릭 몇 번으로 쉽게 길을 찾을 수 있습니다.

📁 내 컴퓨터 탐색기에서 파워쉘 바로 여는 과정
내 PC > 로컬 디스크 (D:) > NewMD
주소창 클릭 ➡️ powershell 입력 후 [Enter] 칠 것!
⬇️ (신비롭게도 해당 폴더에서 바로 열림!)
PS D:\NewMD> _ (여기서 명령어 입력)
🔑 황금 비법 순서 요약
  1. 내 컴퓨터(파일 탐색기)에서 내 작업 폴더(예: D:\NewMD)로 들어갑니다.
  2. 탐색기 맨 위쪽의 주소창(긴 네모 칸)을 마우스로 클릭합니다.
  3. 영어로 powershell 이라고 치고 엔터(Enter)를 칩니다!
  4. 파워쉘이 그 자리(PS D:\NewMD>)에서 바로 열립니다.
CHAPTER 04

실전에서 마주친 4대 돌발 오류 완전 정복

실제 실습 도중 교육생들이 겪는 4가지 난관과 해결책입니다.

🛑 1. 윈도우 터미널 보안 경고 팝업
⚠️ 경고: 여러 줄이 있는 텍스트를 붙여 넣습니다. 계속하시겠습니까?
[붙여넣기] ⬅️ 클릭! [취소]
👉 해결책: 윈도우의 정상적인 확인 창입니다. 파란색 [붙여넣기]를 누르거나 엔터를 치시면 됩니다.
🛑 2. Author identity unknown (사용자 등록 오류)
fatal: unable to auto-detect email address (got '이윤재@Seisgang.(none)')
*** Please tell me who you are.
👉 해결책: 깃(Git)에 내 이름과 이메일을 등록하면 끝납니다:
git config --global user.name "내이름"
git config --global user.email "내이메일@gmail.com"
🛑 3. GitHub 로그인 팝업 (Connect to GitHub)
GitHub Sign in
Sign in with your browser ⬅️ 클릭!
👉 해결책: 파란색 버튼을 누르면 브라우저 창이 열리며 초록색 Authorize 버튼만 한 번 누르면 끝납니다!
🛑 4. 코드가 잘려 >> 상태로 멈췄을 때
>> const VALID_PW = "1968
>> _ (엔터를 쳐도 반응이 없음)
👉 해결책: 만병통치 단축키 Ctrl + C 를 누르면 즉시 취소되고 원래의 PS D:\NewMD>로 깨끗하게 탈출합니다!
CHAPTER 05

Vercel과 GitHub로 전 세계 무료 배포하기

코드를 수정한 뒤 전 세계에 있는 내 스마트폰으로 전송하는 마법의 3단계 명령어입니다.

🚀 클라우드 자동 배포 파이프라인
1. git add . ➡️ 수정한 파일들을 배포 상자에 담기
2. git commit -m "내용" ➡️ 상자에 테이프 붙이고 이름표 달기
3. git push origin master ➡️ 깃허브와 Vercel 클라우드로 번개 전송!
💡 Vercel 배포 무조건 성공 꿀팁

git push origin master:main 명령어를 함께 실행해 두면, 깃허브의 master와 main 양쪽 브랜치로 모두 복사되므로 Vercel이 어떤 설정을 쓰더라도 1분 안에 100% 자동 배포됩니다.

CHAPTER 08

시니어 교육 현장 지도 꿀팁 (강사용 지침)

👨‍🏫 성공적인 시니어 코칭 3원칙
  1. 마우스 드래그를 금지하고 [복사] 버튼을 가르쳐라:
    시니어 교육생들은 마우스 왼쪽 버튼을 누른 채 긴 글씨를 긁어내리는 동작에서 90% 이상 실패합니다. 코드 상자 우측 상단의 [복사] 아이콘을 클릭하게 하면 실패율이 0%가 됩니다.
  2. "에러는 고장이 아니라 컴퓨터가 길을 물어보는 것":
    빨간 글씨나 경고창이 뜰 때 두려워하지 말고 스마트폰으로 화면을 찍어 AI에게 물어보도록 지도하면 학습자들의 디지털 공포가 사라집니다.
  3. 내 폰에 앱이 깔리는 순간의 '자기효능감':
    "코딩 한 줄 모르는 내가 내 병을 관리하는 앱을 만들었다"는 경험은 시니어 세대에게 엄청난 자존감과 삶의 활력을 선물합니다.
