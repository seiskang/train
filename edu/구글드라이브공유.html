Google Drive 200GB Pro Guide

구글 드라이브 대용량 파일 연동 및 공유 보안 관리

📂 PART 1. 웹(HTML) 대용량 파일 직접 연동 가이드

01
파일 업로드 및 공유 권한 설정: 구글 드라이브에 오디오·이미지 업로드 후, 우클릭 ➔ [공유] ➔ [공유] 진입. 일반 접근 권한을 '링크가 있는 모든 사용자에게 공개'로 변경 후 링크 복사.
02
웹 전용 직접 재생(Download) URL 변환: 웹페이지(<audio> 또는 <a> 태그)에서 막힘없이 재생되도록 아래 형식으로 변환하여 적용
📌 원본 링크: https://drive.google.com/file/d/【파일ID】/view?usp=sharing
🚀 변환 형식: https://docs.google.com/uc?export=download&id=【파일ID】

🔒 PART 2. 드라이브 파일 공유 상태 점검 및 확인 방법

A
웹 메뉴에서 직접 확인: 왼쪽 메뉴 [공유 문서함] 확인 및 개별 파일 우클릭 ➔ [공유]에서 권한 확인·차단(제한됨). (※ 파일 아이콘에 사람 그림이 있으면 공유 중인 상태)
B
검색창 명령어로 전체 공개 파일 일괄 조회: 드라이브 상단 검색창에 아래 명령어를 입력하여 의도치 않은 외부 노출 파일 점검
🔍 검색 명령어 입력: visibility:public_on 또는 sharedwith:public
