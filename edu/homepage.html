인공지능 비서 부르기: 생성형 AI에게 내 32년 인생 이야기 말하기

"코딩 문법? 영어 약어? 하나도 외우실 필요 없습니다!"

홈페이지의 핵심은 현란한 기술이 아니라 '나의 진솔한 인생 스토리와 전문성'입니다. 저는 32년 철도 공직 경력과 한국어 강사로서의 포부를 AI에게 한국말로 다정하게 이야기했습니다.

📋 실제 seiskang.kr 완성에 사용된 마법의 실전 프롬프트
안녕하세요? 저는 은퇴 후 인생 2막을 준비하는 60대 강사이자 작가 이윤재입니다. 외국인과 성인 학습자들을 위한 1:1 맞춤형 한국어 교육 플랫폼(seiskang.kr) 홈페이지를 만들고 싶습니다. 다음 요구사항을 모두 충족하는 index.html 단일 완성 코드를 작성해 주세요: 1. 헤더: '안녕하세요? 한국어 전문강사 세이스강 이윤재입니다' 2. 큰 글씨: 시니어 방문자들도 돋보기 없이 편안하게 읽을 수 있도록 본문 글씨를 크고 시원하게 설정 3. 줄바꿈 비법: 한국어 문장이 어색하게 한 글자씩 쪼개지지 않도록 'word-break: keep-all;' 스타일 필수 적용 4. 소개 섹션: 32년 철도 공직 경력, 전문 자격증, 평생교육 활동 소개 5. 수강 안내: 1회 50분 $22 USD 맞춤형 수업 안내 및 환불 규정 표 6. 소통 버튼: 카카오톡 보이스톡 상담 및 이메일 문의 버튼 7. 추가 기능: 상단에 [📢 공지사항]과 [📰 언론 보도]를 누르면 열리는 멋진 팝업 모달창 내장 8. 형식: 복잡한 외부 도구 없이 파일 하나만 복사해서 바로 열 수 있는 완전한 HTML 단일 코드로 제공해 주세요.

CHAPTER 04

실수담 ① 파워쉘의 배신과 마우스 웹 배포의 대반전!

"컴퓨터 화면에 온통 붉은 글씨가 떴을 때 심장이 덜컥 내려앉았습니다."

실제 사건
🚨 파워쉘 빨간 글씨 참사: git 용어가 인식되지 않습니다
파워쉘 창을 켜고 `git pull`을 쳤더니 화면 가득 빨간색 에러 메시지가 쏟아졌습니다.
"git: 'git' 용어가 cmdlet, 함수, 스크립트 파일 또는 실행할 수 있는 프로그램 이름으로 인식되지 않습니다."
순간 컴퓨터가 고장 난 줄 알고 식은땀을 흘렸습니다.
💡 명쾌한 대반전과 해결책:
알고 보니 컴퓨터에 'Git'이라는 프로그램이 안 깔려 있었던 것뿐이었습니다!
하지만 프로그램을 힘들게 깔 필요가 전혀 없었습니다. 깃허브 웹사이트([github.com])에서 연필 아이콘(수정)을 누르고, 코드를 붙여넣은 뒤 초록색 [Commit changes] 버튼만 누르면 마우스 클릭 2번으로 1초 만에 전 세계에 똑같이 배포되었습니다!
CHAPTER 05

실수담 ② 화면 폭망 사건: "너무 허접해 보임..."

"코드를 넣고 신나서 사이트를 열었더니... 텍스트가 와르르 쏟아져 나왔습니다."

실제 사건
🚨 서식 쏟아짐 참사: 팝업은 안 뜨고 로그인 밑으로 글씨가 와르르
기대감에 부풀어 seiskang.kr을 새로고침했는데, 팝업창은커녕 로그인 화면 밑으로 글씨가 수십 줄 쏟아져 나와 한 덩어리로 깨져 있었습니다. 절로 "너무 허접해 보임..."이라는 한숨이 나왔습니다.
💡 원인과 해결책:
외부 디자인 도구(Tailwind)가 연결되지 않아 팝업을 숨겨주는 기능이 작동하지 않았던 것입니다.
외부 도구에 기대지 않고 다크 네이비 색상과 테두리 서식(CSS)을 파일 안에 100% 자체 내장시키는 '일체형 완성 코드'로 교체하자마자, 거짓말처럼 널려 있던 글씨들이 싹 사라지고 우아한 팝업창으로 대변신했습니다!

실수담 ④ "어디에 있어? 없거든!" ➔ 상단 전진 배치의 대승리

"버튼을 만들었다는데... 화면 어디에도 안 보이는 숨바꼭질이 시작되었습니다."

실제 사건
🚨 버튼 실종 사건: 관리자로 로그인하면 사라지는 버튼
버튼을 넣었다고 해서 확인하러 들어갔는데, "뭐야, 어디에 있어? 없거든!" 소리가 절로 나왔습니다.
알고 보니 로그인 전 첫 화면에만 버튼을 달아놔서, 관리자로 로그인하니까 대시보드 화면으로 전환되면서 버튼이 쏙 숨어버린 것이었습니다.
💡 디자인 혁신과 해결책:
1. 관리자 상단 로그아웃 옆에 `[📰 언론 보도 관리]` 버튼을 추가했습니다.
2. 그리고 기존 메인의 파란색 타원 배지(`이윤재 선생님`)를 과감히 삭제하고, 그 자리에 `[📢 공지사항]`과 `[📰 언론 보도 / 뉴스룸]` 듀얼 버튼을 전진 배치했습니다!
➔ 이제 손님들이 사이트에 오자마자 신뢰도 높은 공지사항과 언론 기사를 1초 만에 볼 수 있게 되었습니다.

실수담 ⑤ 가짜 비번 사건과 토큰 오타 잡기

실제 사건
🚨 비번 미반영 사건: 유효하지 않은 링크 오류
재설정 링크를 아무리 눌러도 "유효하지 않은 링크입니다"라고 뜨고, 임시 창에서 변경 성공이라고 떴는데도 실제로는 로그인이 안 되었습니다.
💡 진짜 원인과 해결:
코드에서 resetTokenMatch 뒤에 `` 번호가 빠져서 깨진 글자가 서버로 전달되었던 작은 오타 때문이었습니다!
이를 계기로 매번 링크를 찾아다니지 않고, 관리자 화면에서 버튼 하나만 누르면 새 비밀번호를 즉시 바꾸는 [비밀번호 직접 변경 팝업]을 구축하여 영구 해결했습니다.
