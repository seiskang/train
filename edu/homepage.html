생성형 AI로 만드는 나만의 명품 홈페이지

말 한마디로 홈페이지가 완성되는 생성형 AI 시대! 복잡한 프로그래밍 언어 없이 나만의 멋진 인터넷 세상을 직접 열어보세요.

👨‍🏫 강사: 청랑(淸浪) 이윤재 원장 🌐 플랫폼: seiskang.kr 📖 실습 기반 맞춤형 가이드
[그림 1] 나만의 홈페이지를 완성하는 3가지 마법의 기둥
제 1 장

준비 운동: 크롬(Chrome) 브라우저와 친해지기

인터넷 세상으로 나아갈 때 가장 먼저 열어야 하는 문이 바로 '웹 브라우저'입니다. 인공지능 도구들과 가장 호환성이 뛰어난 구글 크롬(Google Chrome)을 기본 도구로 사용합니다.

1
크롬 브라우저 실행하기
바탕화면에서 빨강, 노랑, 초록, 파랑 4색 원형 아이콘(Chrome)을 찾아 마우스로 더블클릭합니다.
2
주소창(URL)에 사이트 이름 입력하기
화면 맨 위 길쭉한 흰색 검색창을 '주소창'이라고 부릅니다. 여기에 naver.com 이나 github.com 을 입력하고 엔터(Enter)를 치면 해당 사이트로 곧바로 이동합니다.
💡 [시니어 꿀팁] 눈이 침침하고 글씨가 작을 때!
키보드 왼쪽 아래의 `Ctrl` 키를 누른 채로 `+` 키를 1~2번 눌러보세요. 화면 글씨가 큼직하게 확대되어 눈이 아주 편안해집니다. (원래대로 돌리려면 `Ctrl` + `0`)
제 2 장

내 집 주소 만들기: 닷홈(Dothome) 가입과 도메인 준비

현실 세계의 '도로명 주소'처럼, 인터넷 세상에서도 나만의 고유한 문패 주소가 필요합니다. 이것을 '도메인(Domain)'이라고 부릅니다. (예: seiskang.kr)

1
닷홈 사이트 접속 및 회원가입
크롬 주소창에 dothome.co.kr을 입력하고 엔터를 누릅니다. 우측 상단의 [회원가입]을 누른 뒤 휴대폰 인증을 거쳐 가입을 완료합니다.
2
원하는 도메인 이름 검색하기
상단 메뉴 [도메인] ➔ [도메인 등록/검색]을 클릭합니다. 본인의 영문 이름이나 호, 브랜드명(예: myname, yoonjae)을 입력하고 [검색]을 누릅니다.
3
나만의 주소 신청 및 결제
마음에 드는 도메인(예: .kr 또는 .com) 옆의 [선택] 버튼을 누르고 등록을 완료합니다. (1년 기준 약 1~2만 원 선)
💡 [시니어 꿀팁] 좋은 도메인 이름을 짓는 비결!
1. 알파벳 5~8자 이내로 짧을수록 타이핑하기 좋습니다.
2. 전화 통화로 상대방에게 말로 알려줄 때 발음하기 쉬운 단어가 최고입니다.
3. 가입한 닷홈 아이디, 비밀번호, 구매한 도메인은 반드시 종이 수첩에 볼펜으로 메모해 두세요!
제 3 장

평생 무료 인터넷 보관 창고: 깃허브(GitHub) 가입하기

깃허브(GitHub)는 마이크로소프트가 운영하는 전 세계 1위 소프트웨어 보관소입니다. 매월 나가는 서버 비용이 0원(평생 완전 무료)이며, 내 홈페이지 파일을 안전하게 평생 보관해 줍니다.

1
깃허브 사이트 가입 (github.com)
주소창에 github.com을 입력하고 [Sign up]을 누릅니다.
(영어 메뉴가 낯설다면 화면 빈 곳 우클릭 ➔ [한국어로 번역]을 누르세요!)
2
내 홈페이지 전용 저장소(Repository) 만들기
로그인 후 좌측 상단의 초록색 [New] 버튼을 누릅니다. 저장소 이름(Repository name)에 homepage 라고 적고, [Public] 선택 후 맨 아래 [Create repository]를 누릅니다.
제 4 장

AI 비서에게 말로 시키기: 생성형 AI 프롬프트 실습

복잡한 프로그래밍 언어를 외울 필요가 없습니다. 생성형 AI(Gemini, ChatGPT)에게 한국말로 "어떤 홈페이지를 만들어줘"라고 사람에게 부탁하듯 대화하면 1초 만에 완성형 코드가 나옵니다.

📋 그대로 복사해서 쓰는 생성형 AI 실전 프롬프트
안녕하세요? 저는 은퇴 후 인생 2막을 준비하는 60대 강사이자 작가 이윤재입니다. 외국인과 일반 학습자들을 위한 1:1 맞춤형 한국어 교육 플랫폼 홈페이지를 만들고 싶습니다. 다음 요구사항을 모두 충족하는 index.html 단일 완성 코드를 작성해 주세요: 1. 메인 헤더: '안녕하세요? 한국어 전문강사 세이스강 이윤재입니다' 2. 글자 크기: 시니어 방문자들도 편하게 읽을 수 있도록 폰트를 크고 시원하게 설정 3. 줄바꿈 비법: 한국어 문장이 어색하게 한 글자씩 잘리지 않도록 'word-break: keep-all;' 스타일 필수 적용 4. 소개 섹션: 32년 철도 공직 경력, 전문 자격증, 평생교육 활동 소개 5. 수강 안내: 1회 50분 $22 USD 맞춤형 수업 안내 및 환불 규정 표 6. 소통 버튼: 카카오톡 보이스톡 상담 및 이메일 문의 버튼 7. 추가 기능: 상단에 [공지사항]과 [언론보도]를 누르면 열리는 멋진 팝업 모달창 내장 8. 형식: 외부 도구 설치 없이 복사해서 바로 쓸 수 있는 단일 HTML 완성 코드로 작성해 주세요.

위 프롬프트를 복사하여 AI 채팅창에 넣고 질문하시면, AI가 완벽한 HTML 코드를 작성해 줍니다.

제 5 장

마우스로 1분 만에 깃허브에 올리고 전 세계 배포하기

1
깃허브에서 index.html 파일 만들기
저장소 화면에서 [Add file] ➔ [Create new file]을 누릅니다. 파일 이름에 반드시 index.html을 소문자로 적습니다.
2
코드 붙여넣기 및 저장(Commit)
넓은 입력창에 마우스를 대고 `Ctrl + V` (붙여넣기)를 한 뒤, 우측 상단 초록색 [Commit changes...] 버튼을 2번 누릅니다.
3
무료 배포 켜기 (GitHub Pages)
저장소 상단 [Settings] ➔ [Pages]로 들어간 뒤, Branch를 `main`으로 바꾸고 [Save]를 누르면 1분 뒤 전 세계 어디서든 열리는 사이트가 완성됩니다!
제 6 장

직접 겪어본 실전 노하우: 명품 디테일 완성하기

✨ 비법 1: 한국어 글자가 한 글자씩 쪼개지지 않는 비결
컴퓨터 화면 너비가 줄어들 때 "이윤재입니 / 다." 처럼 한 글자만 어색하게 다음 줄로 떨어지는 것을 막으려면 CSS 스타일에 word-break: keep-all; 속성을 넣어주면 단어 단위로 깔끔하게 떨어집니다.

🔒 비법 2: 관리자만 글을 쓸 수 있는 공지·보도자료 게시판
일반 방문자에게는 글쓰기/수정/삭제 버튼이 일체 보이지 않고, 원장님이 관리자로 로그인했을 때만 화면 상단에 [✏️ 새 글 등록] 버튼이 나타나도록 설계하여 안전하게 사이트를 운영할 수 있습니다.

시니어 학습자 필수 컴퓨터 단축키 7선

단축키 이름 기능 설명
Ctrl + C 복사하기 선택한 글자나 코드를 컴퓨터 메모리에 복사합니다.
Ctrl + V 붙여넣기 복사한 내용을 원하는 위치에 그대로 붙여넣습니다.
