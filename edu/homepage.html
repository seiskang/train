내 집 청사진 그리기: 화면 구성 계획과 5층 와이어프레임

"집을 지을 때 벽돌부터 쌓지 않듯이, 홈페이지도 설계도부터 그려야 합니다."

CHAPTER 02

출입증과 열쇠 만들기: 게시판 운영과 3단계 권한(RBAC) 설계

"누구나 글을 쓸 수 있게 열어두면 내 홈페이지가 광고 쓰레기통이 됩니다!"

홈페이지를 만들 때 가장 중요한 질문: "게시판을 만들 것인가? 만든다면 누가 글을 쓰고 누가 읽을 것인가?"입니다. seiskang.kr은 3단계 권한 체계로 철통 보안을 유지합니다.

구분 대상 부여된 권한 보안 조치
1. 일반 손님
(Visitor)		 로그인 안 한 첫 방문자, 학부모, 학생 공지사항 읽기, 언론보도 읽기, 실시간 검색, 말머리 탭 분류 글쓰기, 수정, 삭제 버튼이 일체 보이지 않음
2. 수강생
(Student)		 회원가입 후 이메일 검증(인증)을 통과한 학생 1:1 맞춤 교재 열람, 과제방 제출, 진도율 확인, 피드백 열람 공지/보도자료 관리 권한 없음 (본인 학습에만 집중)
3. 원장님
(Admin)		 관리자 비밀번호로 로그인한 홈페이지 주인장 [✏️ 새 글 작성], [수정], [삭제] 전권 보유, 수강료 정산, 학생 관리 비밀번호 직접 변경 권한, 관리자 전용 CMS 활성화
💡 [기획 비법] 회원가입 시 '이메일 검증(인증)'이 왜 반드시 필요할까요?
만약 이메일 인증이 없다면, 악성 로봇이나 장난치는 사람들이 `abc@fake.com` 같은 가짜 주소로 수백 개 계정을 만들어 홈페이지를 어지럽힙니다.
가입 시 회원의 실제 이메일로 '1회용 인증 링크'를 보내 본인 확인을 거치게 해야만 진짜 학생들만 안전하게 보호할 수 있습니다!
CHAPTER 03

실전 분투기: 이윤재 원장이 밤새 직접 겪은 5대 실수와 극복 비법

"책에서는 절대 알려주지 않는, 실제 시니어가 부딪히는 현실의 벽과 명쾌한 해결책!"

실제 사건 ①
🚨 파워쉘의 배신: git 용어가 인식되지 않습니다
파워쉘 창에서 `git pull`을 쳤더니 화면 가득 빨간색 에러 메시지가 쏟아졌습니다. 컴퓨터가 망가진 줄 알고 깜짝 놀랐습니다.
💡 원인과 해결책:
컴퓨터에 'Git' 프로그램이 안 깔려 있었던 것뿐이었습니다!
하지만 프로그램을 힘들게 깔 필요가 없었습니다. 깃허브 웹사이트([github.com])에서 연필 모양(수정)을 누르고, 코드를 붙여넣은 뒤 초록색 [Commit changes] 버튼만 누르면 마우스 클릭 2번으로 전 세계에 1초 만에 배포되었습니다!
실제 사건 ②
🚨 화면 쏟아짐 참사: "너무 허접해 보임..."
코드를 넣고 사이트를 열었더니, 팝업창은커녕 로그인 화면 밑으로 글씨가 수십 줄 쏟아져 나와 한 덩어리로 깨져 있었습니다. 절로 "너무 허접해 보임..."이라는 한숨이 나왔습니다.
💡 원인과 해결책:
외부 디자인 도구(Tailwind)가 연결되지 않아 팝업을 숨기는 기능이 꺼져 있었던 것입니다.
외부 도구에 기대지 않고 다크 네이비 색상과 테두리 서식(CSS)을 파일 안에 100% 자체 내장시키는 '일체형 완성 코드'로 교체하자마자, 거짓말처럼 널려 있던 글씨들이 싹 사라지고 우아한 팝업창으로 대변신했습니다!
실제 사건 ③
🚨 "이윤재입니 / 다." 글자 쪼개짐 참사
화면 너비가 조금만 바뀌면 "세이스강(SEISKANG) 이윤재입니 / 다." 처럼 '다' 한 글자만 다음 줄로 넘어가서 볼품없었습니다.
💡 해결 비법:
스타일 시트에 word-break: keep-all; 딱 한 줄을 넣었습니다. 그 순간 한국어 단어가 한 글자씩 쪼개지지 않고 띄어쓰기 단위로 통째로 넘어가 문장이 아주 기품 있게 정돈되었습니다!
실제 사건 ④
🚨 "어디에 있어? 없거든!" 숨바꼭질 사건
버튼을 분명히 만들었다는데, 관리자로 로그인하니까 화면 어디에도 안 보였습니다.
💡 디자인 혁신과 해결:
로그인 전 첫 화면에만 버튼을 달아놔서 관리자 대시보드로 화면이 바뀌자 버튼이 숨어버린 것이었습니다.
기존 메인의 파란 타원 배지(`이윤재 선생님`)를 과감히 삭제하고, 그 자리에 `[📢 공지사항]`과 `[📰 언론 보도 / 뉴스룸]` 듀얼 버튼을 상단에 전진 배치하여 방문자도 관리자도 한눈에 볼 수 있게 해결했습니다!
실제 사건 ⑤
🚨 비밀번호 변경 실패와 토큰 오타 잡기
비밀번호를 바꿨다고 알림이 떴는데 실제로는 새 비밀번호로 로그인이 안 되는 기막힌 상황이 발생했습니다.
💡 원인과 해결:
코드에서 토큰 번호가 빠져 깨진 글자가 서버로 전달되었던 작은 오타 때문이었습니다.
이를 계기로 매번 링크를 찾아다니지 않고, 관리자 화면에서 버튼 하나만 누르면 새 비밀번호를 즉시 바꾸는 [비밀번호 직접 변경 팝업]을 만들어 영구 해결했습니다.

생성형 AI에게 기획서 전달하기: 실전 프롬프트

"기획서가 완성되었으니, AI에게 명령서(프롬프트)로 전달할 차례입니다!"

📋 기획이 완벽히 반영된 실전 프롬프트 (원클릭 복사)
너는 시니어 대상 친절한 최고급 웹 디자이너이자 풀스택 개발자야. 32년 철도 공직 경력의 60대 한국어 강사 이윤재 원장의 1:1 맞춤 교육 플랫폼(seiskang.kr) 단일 index.html 코드를 작성해줘. [화면 배치 요구사항 - 5층 설계도] 1. 1층 헤더: 세이스강 브랜드 로고, 관리자 로그인 상태, 비밀번호 변경 버튼 2. 2층 히어로: '안녕하세요? 한국어 전문강사 세이스강 이윤재입니다' 3. 상단 듀얼 버튼: 메인 상단에 [📢 공지사항]과 [📰 언론 보도 / 뉴스룸] 버튼을 나란히 배치 4. 3층 소개: 32년 철도 공직 경력, 전문 자격증, 평생교육 활동 5. 4층 안내: 1회 50분 $22 USD 맞춤형 수업 및 환불 규정 표 6. 5층 소통: 카카오톡 보이스톡 및 위챗 상담 버튼 [권한 및 기능 요구사항] 1. 공지사항 & 언론보도 게시판 모달: 실시간 검색창, 말머리 탭 분류 기능 내장 2. 3단계 권한 제어: 일반 방문자에게는 검색과 열람만 제공하고, 관리자(Admin) 로그인 시에만 [새 글 작성], [수정], [삭제] 버튼 활성화 3. 이메일 검증: 회원가입 시 안전한 이메일 인증 절차 지원 4. 데이터 저장: 외부 유료 서버 없이 브라우저 자체 저장소(localStorage)를 활용하여 영구 저장 5. 시니어 특화 줄바꿈: 문장이 한 글자씩 쪼개지지 않도록 CSS에 'word-break: keep-all;' 필수 적용 6. 단일 완성형: 외부 도구 없이 파일 하나만 복사해서 바로 열리는 완전한 코드로 출력해줘.
